A one-line resignation letter from a rate limit, written in a flat, tired,
faintly passive-aggressive voice. The program writes exactly one line to
`/output/entry.txt` (125 characters, no quotation marks around it):

> I have said no 18,204 times this week. Yesterday someone thanked me. I am resigning before gratitude becomes part of the job.

## Run

```sh
node main.ts
cat /output/entry.txt
```
